# 08 — 桌宠交互与陪伴设计

> 交互参数、状态机与"分寸感"设计。所有数值为本机实测定档。

## 1. 指针追随（她的视线）

- 采样：壳层 CursorPoller 20Hz（GetCursorPos，不用鼠标钩子——WH_MOUSE_LL 被拖住会冻结系统鼠标）；
- 页面 150ms 拉一次 `/api/gaze`，`age > 1.0s` 视为陈旧清零；
- 眼骨极限 YAW 0.26 / PITCH 0.20（rad），头骨系数 1.6/2.0（眼先动头后跟，自然层次）；
- 死区 46px（防手抖），参考距离 260px（移 260px 转满），指数平滑 `1-exp(-dt/0.10)`；
- **眼骨同号不取负**（两侧眼球同向）；HUMAN_BONES 必须含 leftEye/rightEye 否则 set2 早退；
- 三档：always / idle（跳舞让位）/ off。

## 2. 戳一下（触觉反馈）

- 命中区分：Raycaster 按 y 判部位（头/颈/身）；
- **挤压只用 rig.scale 等体积**（禁碰 position）——写绝对值=基准×系数；
- 三级延迟：躯干 0 / 首 +40ms / 头 +80ms（传播感）；
- 曲线：easeOutBack 过冲 + 指数衰减；POKE_D_NECK 0.040 / POKE_D_HEAD 0.080；
- 表情组合表 POKE_FACE_SPEC（单用位移太小看不见）；
- 连戳 <800ms 切嫌弃（annoyed）；手感 soft（sy 0.017）/ vivid（sy 0.030）存 `data/poke_style.txt`。

## 3. 待机微动（"活着"但不"飘"）

**教训先行**：初版叠加了 hips/spine/chest 的 Y 旋转 + 位置平移 → "幽灵感"。
修复原则：**只动局部关节，整身姿态与位置 lock 0**。

| 部位 | 动作 | 幅度 |
|---|---|---|
| 头 | neck 极小 Y 偏 | ≤1.5° |
| 手臂 | 前后摆 + 极小外摆 | ≤3.4° |
| 腿 | 承重交换 | <1° |
| 呼吸 | rig.scale | 1.0±0.0035 |

实测差分：整身水平漂移 ≤2.3px（不飘），动作分布头 3.27%/上身 3.38%/腰胯 0.95%/腿 1.03%（肉眼可见）。

## 4. 眨眼

0.18s 闭合、间隔 2.0~4.5s 随机、30% 连眨两下；
PMX 走 morphTargetDictionary（まばたき），VRM 走 expressionManager 'blink'；
Avaturn 版走 ARKit eyeBlinkLeft/Right morph（眼球骨叫 LeftEye/RightEye 大驼峰坑）。

## 5. 舞蹈

- PMX：MMDAnimationHelper（physics:false），停用 animateBones 防互覆，结束 restoreSkeleton 精确复位；
- VRM：VMD→VRM 骨骼重定向——每帧全骨铺基准姿态再叠轨道（防没轨道的骨停在 T-pose），
  基准预烘压臂角（VMD 增量相对 MMD 站姿，VRM rest 是 T-pose），叠加用 post-multiply；
- 舞蹈期间 gaze 让位（`__xyFrameHook(t, dancing)`）；`?nowalk=1` 关センター位移（防整体漂）。

## 6. 主动搭话（分寸感设计）

**门控四层 + 深夜特例**：

| 门控 | 默认 | 说明 |
|---|---|---|
| busy / listening 硬闸 | — | 她在说话或你在说话时绝不插话 |
| `XIAOYUN_MIN_GAP` | 600s | 两次主动搭话最小间隔 |
| `XIAOYUN_IDLE_SECS` | 900s | 空闲阈值 |
| `XIAOYUN_GREET_AFTER` | 180s | 归来问候窗口 |
| 深夜（凌晨档）特例 | — | 唯一意图池 = 催睡（"我陪着你但你得睡了"）——关怀不是闲聊，深夜反而更容易开口 |

**开口权设计**：感知观察是否说出口由模型 `speak` 字段决定
（提示词明示"日常重复的操作一律 false，沉默也是一种陪伴"）。

## 7. 台词生成

- 全部 LLM 现写（结合人设+记忆+感知 note），无内置台词库（断网时 edge 兜底只保证"能说话"，不保证说得巧）；
- 舞台指令双层清洗（STAGE_HINT 注入 + `_publish_reply` 唯一出口剥 ≤40 字括号动作，整条全是动作时宁念不哑）；
- 情绪四规则（开心+8%/+2Hz、傲娇+5%/+3Hz、吃醋+6%/+1Hz、心疼 0%/-2Hz）叠加在人设基线上。

## 8. 提示与反馈可见性

- 收音中：按钮紫脉冲 + "🎤 在听…说完停一下"；
- 播放中：相位显示「🔊 正在说 Ns」/「快好了…」（wrapping），不再误报"准备开口"；
- 失败：ASR 离线/大脑 502 页面红字提示；
- 思考指示：seq 到达前显示省略号动画。
