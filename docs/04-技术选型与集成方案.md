# 04 — 技术选型与集成方案

> 每个关键选型的候选对比、实测数据与最终决策。全部为本机实测，非纸面推断。

## 1. 桌面壳：pywebview（而非 Electron / CEF / Qt）

| 候选 | 结论 | 理由 |
|---|---|---|
| **pywebview 6.2** ✅ | 选用 | Python 生态原生、WebView2 渲染、体积小；透明/无边框/托盘均可做 |
| Electron | 否决 | 重（~200MB 运行时）；本项目 Python 后端为主，跨语言 IPC 徒增复杂度 |
| CEF (cefpython) | 否决 | 维护停滞，透明支持差 |
| Qt/PySide | 否决 | 与 Web 前端（three.js/VRM）路线冲突 |

**代价与对策**：WebView2 在色键透明窗口收不到鼠标事件（微软已知限制）→ 自研 Catcher 隐形点击层；
pywebview JS 桥是同步回环 → 高频数据全部改走本地 HTTP。

## 2. 透明方案演进（四代）

1. ~~pywebview `transparent=True`~~ → WinForms BackColor 透出白幕；
2. ~~页面刷品红 + 色键~~ → WebView2 走 DirectComposition，色键抠不动页面像素；
3. **WinForms 底色刷品红 + TransparencyKey + WS_EX_LAYERED 色键** ✅（现方案）；
4. ~~全局鼠标钩子补交互~~ → 冻结系统鼠标，永久禁用；隐形点击层（alpha=1/255 独立分层窗）最终胜出。

**验证方法论**：BitBlt 抓屏验证透明是**假验证**（抓不到分层窗口）；
唯一可靠判据 = PrintWindow + PW_RENDERFULLCONTENT 抓窗口自身画面看主色。

## 3. 对话大脑：or_proxy 三上游（而非单接一家 / 本地 LLM 常驻）

| 候选 | 实测 | 决策 |
|---|---|---|
| 本地 Ollama qwen3.5-9b | 占 6.6G/8G 显存，与 3D 渲染抢显存 | **退役**（10-17 起），显存让给渲染 |
| 方舟 ark 直连 | 快（economy 359ms）但单模型 50 万 token 额度易烧光 | **主力**，8~17 模型额度池 + 熔断 |
| 魔搭 Qwen3.5-27B | 免费、27B 质量好，但限流 | 备援 |
| OpenRouter 免费池 | 429 频繁、免费名单月度轮换 | 兜底（上游切换自动回退） |
| AgentPlan 通道 | Plan Key 独立计费池 | arkplan 备援 + 视觉/生图/embedding 专用 |

**架构**：单文件 or_proxy（零第三方依赖），OpenAI 兼容端点；EMA 延迟择优（α=0.35）；
`stream_options.include_usage` 自动注入记账；401 不终止整链只跳档。
**Key 串道防御**：ARK_API_KEY 与 Plan Key 同值时自动告警并改用内置标准 Key（2026-10-23 事故产物）。

## 4. TTS：豆包流式（而非 edge / MiniMax / 本地克隆）

| 候选 | 实测 | 决策 |
|---|---|---|
| **豆包 volc seed-tts-2.0** ✅ | 首包与文本长度无关（2 字 0.41s / 94 字 0.32s），连接复用是关键；流式裸 PCM 24kHz 免解码 | **主引擎**，情绪参数丰富 |
| edge-tts | 免费但音色只有 2 个中文女声，拿不到情绪 | **保底**（豆包挂了她不哑） |
| MiniMax | 御姐系统音色好，但余额不足 | 备选（引擎位保留） |
| GPT-SoVITS 本地 | 克隆声线，BERT 必须 GPU（1.3G fp32 CPU 会段错误） | 可选位（本包未含，10G 权重） |
| StreamVox | 评估后否决：现架构整段播放拿不到流式收益；改流式要先动四处前端契约 | 借设计不借代码 |

**流式实测基准**：整段 2.0s → 流式首块 0.38~0.45s（暖）；冷连接多付 ~0.5s TLS（prewarm 线程解决）。
**切段策略**：首包与文本长度无关 → 不按逗号切（白切且每句多 0.65s 停顿），max_len=60 句号级。

## 5. ASR：三通道路由（而非单 whisper）

| 通道 | 定位 | 实测 |
|---|---|---|
| 豆包流式 sauc | 最快主力 | WebSocket 大模型非流式版 |
| 百度 REST | 云端兜底 | dev_pid=1537（短语音），scope 鉴权判断法 |
| faster-whisper small | 本地兜底 | CPU int8 2.47s 加载；四道质量门 + 幻觉黑名单（修过 initial_prompt 回显教科书级幻觉） |

**VAD 实测教训**：本机环境静音 RMS≈0.00015，她的音箱回授 0.0023~0.0112，用户说话起点 ≈0.0023
——**抬阈值救不了自听循环，只能靠时序**（播放期关麦 + 真实时长上报）。

## 6. 3D 渲染：three-vrm + MMDLoader（而非 Unity/UE）

- Web 技术栈与 pywebview 天然契合，three.js 0.160 + three-vrm 3.5.5 全部本地化（unpkg 被墙，jsdelivr 备份）；
- PMX 走 MMDLoader（FBX 路线否决：Shift-JIS 骨骼名乱码 0/13 匹配）；
- **VRM 两条铁律**：update 传 deltaTime（绝对秒数会顶飞弹簧骨）；禁缩放模型本体（刚度/碰撞半径是世界单位）；
- 取景一律「渲染量真实剪影一次求解」，蒙皮 Box3 只有 T-pose 不可信。

## 7. 记忆：SQLite FTS5 + 向量 RRF（而非纯向量库 / mem0 直接用）

| 方案 | 结论 |
|---|---|
| 纯 FTS5 | 中文需分词 → bigram 索引（零依赖且检索场景足够），但只有字面命中 |
| 纯向量（bge-m3） | 语义召回好，但 Ollama 不可用即全瘫 |
| **RRF 融合** ✅ | FTS5 精确 + 向量语义两路召回融合排序；embed 不可用自动退化纯 FTS5 |
| mem0 直接用 | 依赖重；只借**四操作消解**设计（ADD/UPDATE/DELETE/NOOP）自研 memory_brain |

## 8. 屏幕感知：借鉴 WhalePal 管线

直接复用其设计（MIT，已署名）：dhash 9x8（阈值 4 汉明距离）、截屏窗口去重、
13 类活动 JSON 契约、无 Key 降级关键词分类。
差异：whalepal 用 Electron + 云端 VLM 主证据；本包装进 Flask 线程 + 豆包 Vision，截图只活内存不落盘。
