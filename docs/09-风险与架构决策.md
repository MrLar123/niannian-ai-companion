# 09 — 风险与架构决策

> ADR（架构决策记录）与风险登记。每条含撤销条件。

## ADR-001：大脑上云，显存留给渲染
- **决策**：对话 LLM 全部走 or_proxy 云端，本地 Ollama 只留 embed（bge-m3）。
- **背景**：RTX 5050 8GB；qwen3.5-9b 占 6.6G 后 3D 页偶发 OOM。
- **代价**：依赖 API Key 与额度；断网时对话降级（但 TTS/ASR 仍可用 edge/whisper）。
- **撤销条件**：显存 ≥16G 或出现可靠的本地量化路由方案。

## ADR-002：隐形点击层（Catcher）而非透明模式切换
- **决策**：默认全透明 + 独立 alpha=1/255 分层窗接管点击。
- **背景**：色键透明窗口收不到鼠标（微软已知限制）；全局钩子冻结系统鼠标；SetWindowRgn 无效。
- **代价**：多一个消息泵线程，需 watchdog 看护（连续 2 次无响应撤层，宁可不点不能吞输入）。
- **撤销条件**：WebView2 官方修复分层窗口鼠标事件。

## ADR-003：高频数据走本地 HTTP，禁用 pywebview JS 桥
- **决策**：光标/控件坐标/壳心跳全部 HTTP（/api/gaze/cursor、/api/ui/rects、/api/shell/beat）。
- **背景**：JS 桥同步回环在 WebView2 UI 线程执行，高频调用实测堵死 → Ghost 窗 → 吞点击。
- **撤销条件**：pywebview 提供异步桥。

## ADR-004：语音时序由"页面上报真实时长"驱动
- **决策**：页面周期 POST /api/voice/playing {seq,dur}（audio.duration），后端按 start+dur+0.8 恢复收音。
- **背景**：MP3 字节数估算偏短 40%+，五轮自听死循环的总根因。
- **撤销条件**：TTS 引擎提供字级时间戳。

## ADR-005：单文件 or_proxy（零依赖）而非框架化网关
- **决策**：http.server + urllib 纯标准库，别名/熔断/记账全内置。
- **代价**：无异步（单请求阻塞线程池）；功能受限。
- **收益**：任何机器 python 直跑；出问题 grep 一个文件就完。
- **撤销条件**：需要高并发或 SSE 复杂路由时升级 FastAPI。

## ADR-006：PMX 与 VRM 双页并存，不合并渲染器
- **决策**：desktoppmx.html（MMDLoader）与 desktopvrm.html（three-vrm）两套页面，壳按 PET_PAGE 选择。
- **背景**：两者的骨骼/材质/物理体系完全不同，合并渲染器成本 >> 维护两页。
- **已知限制**：跨类型切模型需重启壳（托盘切同类型秒生效）。
- **撤销条件**：出现统一加载层。

## ADR-007：bat 纯 ASCII / ps1 带 BOM 的编码纪律
- **决策**：所有 .bat 0 非 ASCII 字节；中文一律进带 BOM 的 .ps1；GBK+CRLF。
- **背景**：UTF-8 中文被 cmd 按 GBK 解码后切断命令行（用户连报三次"双击无反应"的最终根因）。
