## 一、口径

桌宠的表情有没有「看得见」，用一个量：**可见度 vis**。
做法是把该表情单独摆到模型脸上，跟中性脸逐像素比，再合成三项：

```
vis = 改动像素占比(%)  +  峰值16×16分块平均差 × 0.04  +  平均差 × 1.0
```

| 分数区间 | 观感 |
|---|---|
| ≥ 2.0 | 很明显 |
| 1.0 ~ 2.0 | 明显（参考：全闭眼 ≈ 1.5~2） |
| 0.5 ~ 1.0 | 清楚可见 |
| 0.2 ~ 0.5 | 轻微，凑近能看出来 |
| < 0.2 | 基本看不见 |

三项各管一类变化，缺一不可：面积管「大面积强变化」（闭眼笑、睁大眼）；峰值管「细小但局部很强」（眼睛一眯、眉毛一压）；平均差管「整片均匀的低幅度变化」——脸红染色就是这一类，面积可能为 0 但整张脸都轻微偏红，只看面积会误判成没效果。
不掺姿态（歪头/低头）——姿态在任何模型上都明显，会把「表情几乎没动」掩盖掉。

## 五、这一轮修掉的东西

| 缺陷 | 现象 | 根因 | 修法 |
|---|---|---|---|
| 表情只写一个网格 | 脸/眼/口是独立网格的模型上「算了但脸不动」 | PMX 按材质拆网格，各带一份 morph 字典 | 按**名字**跨全部网格写入 |
| 闭眼笑被当成微笑 | happy 时角色闭着眼，像在睡觉 | 选表情只按「最明显」，而闭眼笑改动面积最大 | smile 槽位加**睁眼优先**硬约束：睁眼笑够亮才用它；睁眼笑几乎为零（< 0.5）时退回闭眼笑并把权重压到 0.7，眼睛半闭读作眯眼笑，也好过「睁着眼但毫无表情」|
| 标定读数与真机不一致 | 报表写「害羞 2.09」，真机脸上不红 | 探测时按满权重 1.0 量，实际配方只给 0.48 —— 幅度不够的表情在低权重下归零 | 候选一律按**实际生效权重**（配方权重 × 0.8）探测，选出后再按生效权重复测一遍 |
| 强表情被弱表情挤掉 | feixue「好奇」只有 0.38，明明有更亮的「はちゅ」 | morph → 像素不单调：位移要跨过栅格化阈值才出现，0.336 权重下「はちゅ」是 0、0.672 下是 1.70。只按基础权重量一轮，会把「放大后才发光」的表情全部漏掉 | 最高分不足 1.0 时再做一轮**放大权重**探测，谁在真机权重下更亮就用谁 |
| 睁眼笑/闭眼笑判定漂浮 | 同一个 peier，两次标定给出相反的结论 | 界线卡在 0.5，而「喜び」算出来正好 0.50（真闭眼笑都在 0.76 以上，中间是空档）| 界线挪到 0.6，落进空档里 |
| 语义不贴的弱表情占了槽位 | peier 的「温柔」挂在「にやり」上，只有 0.16 | 兜底只在「完全没有平和表情」时才触发，不看选中的那个能不能看见 | 分数不到可见阈值也走兜底，并且取**画面上最亮的笑**压到 0.6 |
| 闭眼笑只有眼睛在动 | 眼睛闭上了，嘴还是平的，读起来像在打瞌睡 | 很多模型的「笑い」只驱动眼睑，嘴角不在同一个表情里 | 判定为闭眼笑时自动补一个「口角上げ」（嘴角上扬），让嘴也跟着笑 |
| 材质型表情不执行 | 「照れ」写多少权重画面都不变 | MMDLoader 对 PMX morph type 8 是 `// TODO: implement` | 拦加载器内部同一份 PMX 解析结果，自己按加算规则写回材质颜色 |
| 脸红贴图缺失 | 「照れ」测出 0.00%，同模型眨眼 1.9% | 不少模型的脸红是一块独立贴片，作者打包漏了那张 png（如 wuluo 的 `表情.png`），空贴图 + MMD 自定义混合 = 什么都不画 | 标定发现原生脸红看不见时，改用**脸材质染色**兜底（伪表情 `__tint`）|

标定口径本身也换过一次：早期用「跨异步任务采样」，读数会整体漂移、同一表情两次能量出差一个数量级；现在把「清零 → 摆表情 → render → readPixels → 算差」压进**同一个同步任务**，噪声实测 0%。
