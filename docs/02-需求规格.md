# 02 — 需求规格

> 功能需求 FR-* 与非功能需求 NFR-*。标注 [新增] 的为迁移改造过程中用户追加的需求。

## 功能需求（FR）

### 陪伴与交互
- **FR-1** 透明置顶桌宠窗口，可拖拽（无边界钳制，可自由出屏），双击/单击身体打开聊天窗。[用户明确要求不加边界]
- **FR-2** 隐形点击层：全透明模式下鼠标可选中、可拖动、可点按钮（Windows 分层窗口限制的绕过方案）。
- **FR-3** 托盘菜单五组子菜单：人设/音色/对话模型/人物模型/动作，全部热切换。
- **FR-4** 戳一下：按命中部位（头/颈/身）差异化挤压反馈，连戳 <800ms 切嫌弃表情，手感 soft/vivid 可调（`data/poke_style.txt`）。
- **FR-5** 眼神追随三档模式：always / idle / off，持久化到 `data/gaze_mode.txt`。
- **FR-6** [新增] 右键菜单与托盘等价：人物模型 radio + 调参入口。

### 形象与动作
- **FR-7** PMX 模型自动发现（扫 `assets/models/*/`），per-model 取景/调色参数（model.json）。
- **FR-8** VRM 模型支持（three-vrm），菜单白名单管控，`{"in_menu":true}` 放行。
- **FR-9** VMD 舞蹈库 15 套，PMX 原生 + VRM 骨骼重定向双支持，舞蹈中眼神让位。
- **FR-10** 眨眼（0.18s、2~4.5s 随机、30% 连眨）+ 待机微动（头/臂/腿/呼吸，整身绝对不漂）。
- **FR-11** 口型同步：非流式（audio.currentTime + 拼音字典）与流式（PCM 20ms 包络）双通道。

### 对话与大脑
- **FR-12** OpenAI 兼容对话接口，多上游自动路由（延迟择优/额度熔断/错误跳档）。
- **FR-13** 19 套人设 JSON 热切换，人设含人格文本+声线+语速+情绪参数。
- **FR-14** 情绪调度：回复文本命中情绪词库 → 语速/音调偏移（开心+8%/+2Hz 等四组）。
- **FR-15** 舞台指令清洗：括号动作描写在唯一发布出口剥离，宁念不哑。
- **FR-16** 对话模型清单 = 顺序表 ∩ 代理实况，当前模型不在清单照样返回（防界面错位）。

### 语音
- **FR-17** ASR 三通道自动路由：豆包流式 → 百度 REST → 本地 whisper，失败自动回落。
- **FR-18** VAD 连续对话模式（默认）与 PTT 按键说话并存，阈值自适应（噪声底×K 夹下限）。
- **FR-19** 播放期真关麦（pause stream + drop queue），resume 委派收尾闸。
- **FR-20** TTS 四引擎：豆包 volc（默认）/ edge 保底 / GPT-SoVITS 本地 / MiniMax 云端。
- **FR-21** 流式 TTS：句号级切段（max_len=60），首响 ≤0.5s。
- **FR-22** [新增] 语音指令路由：停动作/换舞/换音色/换形象四类意图，槽位+别名+编号方案。
- **FR-23** [新增] 主动开口播报时长：页面周期上报 audio.duration，真实时长驱动收音恢复。

### 感知与记忆
- **FR-24** [新增·借鉴 WhalePal] 屏幕周期感知：截屏→dhash 去重→云端视觉→13 类活动分类→事件流。
- **FR-25** [新增] 信号反应：屏幕报错→安慰、任务完成→庆祝（speak 门控决定说不说）。
- **FR-26** [新增] 今日回顾：`/api/context/today` 聚合 + 设置页可视化。
- **FR-27** 长期记忆：SQLite FTS5（中文 bigram）+ bge-m3 向量 RRF 融合，mem0 式四操作消解。
- **FR-28** 情境主动搭话：空闲 900s / 最小间隔 600s / 久别问候 180s / 深夜催睡意图池。

### 运维
- **FR-29** 全链路一键启停/重启/诊断（双击 bat），单实例互斥锁。
- **FR-30** 前端事件日志四层共写（页/壳/后端/ASR 前缀区分），跨天累积。
- **FR-31** Swap-Brain：改 or_proxy 后热换血，其余组件不动。
- **FR-32** 设置页 `/settings`：模型清单/延迟/用量条形图/今日活动。

## 非功能需求（NFR）

| # | 需求 | 指标 | 现状 |
|---|---|---|---|
| NFR-1 | 语音首响 | ≤1s | 0.38~0.45s ✅ |
| NFR-2 | 自听死循环 | 零复发 | 10-17 起 ✅ |
| NFR-3 | 启动时间 | ≤90s | ~70s ✅ |
| NFR-4 | 单实例 | 重复启动被拒 | 命名互斥量 ✅ |
| NFR-5 | 隐私 | 截图不落盘、数据不出 project-nn | ✅ |
| NFR-6 | 断网降级 | 无网仍能说（edge）+能听（whisper） | ✅ |
| NFR-7 | 模型额度 | 可观测（usage 记账）+ 自动省（熔断跳档） | ✅ |
| NFR-8 | GPU 占用 | 对话大脑不占显存（云端） | ✅ 显存留给渲染与 embed |
| NFR-9 | 编码纪律 | bat 纯 ASCII / ps1 带 BOM / GBK+CRLF | ✅ 已固化为铁律 |
| NFR-10 | 可观测 | 任意故障 5 分钟内定位（四层日志+诊断脚本） | ✅ |
