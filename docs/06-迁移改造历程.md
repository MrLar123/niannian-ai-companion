# 06 — 迁移改造历程

> 从 AI-Vtuber 网页版到现在的完整改造史，按天记录。全文版见仓库根 `迁移历程总结_2026-10-16至10-24.md`。

## 时间线

### 10-16：桌面化（浏览器 → Windows 原生）
- pywebview 壳：无边框+透明+置顶+托盘；
- 透明攻坚四代方案（见 04 文档 §2），最终 WinForms 色键 + 隐形点击层；
- 一串硬故障修复：bat 编码（UTF-8 被 GBK 解码切断命令行）、`ollama app.exe` 忽略 OLLAMA_MODELS、
  窗口消息回调昂贵操作致整机卡死、DWM Ghost 替身窗吞点击；
- 形象五连换：Haru(Live2D) → 3D 御姐(GLB) → 2D JK 立绘 →（次日）PMX 姵儿 →（10-21）VRM 小芸；
- qwen2.5:7b → qwen3.5-9b（显存 100% 驻留 + think:false 大坑）。

### 10-17：语音全双工 + or_proxy 诞生
- ASR 上线（faster-whisper CPU int8，三进程架构）；
- **自听死循环五轮根因战**（MP3 时长估算错误 / PLAYBACK 未清零 / vad 不关麦 / 双页同播 / autoplay 拦截谎报）
  → 时序铁律确立；
- VAD 阈值实证（环境静音 0.00015，阈值从 0.012 降到 0.0010）；
- 点击失效连环案（置顶位被系统清掉 → 并入 Catcher；状态文字推按钮横移 → flex-end 锚定；
  JS 桥堵死 UI 线程 → 全部改 HTTP）；
- Whisper 幻觉治理（四道质量门+黑名单）；百度 ASR 兜底；口型同步方案 B（拼音字典+RMS 包络）；
- **or_proxy.py 诞生**（OpenRouter 免费池代理）。

### 10-18：大脑升级 + 工程化
- 魔搭 Qwen3.5-27B 直连 → **or_proxy 三上游**；
- 人设体系（萌娘百科 190 条筛 64 条 → 19 套 JSON）+ 音色独立 + 托盘五组菜单；
- 豆包 TTS 接入（情绪调度 ±8% 语速）；GPT-SoVITS 本地声线；
- 多人物模型（PET_MODELS 自动发现）+ VMD 动作库 9→24 + frameMotion 取景修复；
- **女友改名**：小芸 → 念念（人物名改，工程名/窗口标题是跨脚本契约不动）；
- 启动链硬化（子脚本禁管道、单实例互斥锁）。

### 10-19~10-22：3D 资产管线（本机全流程）
- Hunyuan3D-2mini 本地部署（RTX 5050 sm_120 需 torch cu128）；
- Blender 三阶段：减面 → 绑骨 19 骨 → VRM 导出 → fix_vrm_restpose 必跑；
- 三视图贴图（统一画幅铁律；EDGE_MID 修侧视条纹；UV 退化降权）；
- P0 面部重建（UV 重排 + 频率分离，ΔE<5 全达标）；
- 多视图 Hunyuan3D-2mv（左右视图语义坑、朝向铁律推翻重立）；
- 头身分离（全身生成脸必然平——512² 输入脸只占 42px；只取脸方案 FACE_ONLY）；
- 小芸.vrm/小芸-jk.vrm 接入，VRM 两条铁律实证（deltaTime / 禁缩放）；
- desktopvrm.html 正式版（融合渲染成果+完整交互链）。

### 10-19~10-20：流式语音 + 感知
- tts_stream.py：豆包裸 PCM，首响 2.0s→0.38~0.45s；
- 「她说完不开麦」修复（流式路径 playing 上报缺失）；
- 语音指令路由四分支 + ASR 友好化（别名+编号）；
- 方舟额度池 + 熔断 + usage 记账 + auto 路由；
- 屏幕感知上线（perception.py，借鉴 whalepal）+ events_store + 今日回顾。

### 10-23~10-24：形象定稿 + 收尾
- Avaturn 照片重建三版迭代 → FINAL（黑长直调色，187 morph，glb_swap_tex 原地重建 GLB）；
- glb2vrm.py 转 VRM（表情 preset 绑定，bind.index 是 StringProperty）；
- arK Key 串道事故修复；
- 舞台指令禁令（797 条括号动作回复被 TTS 念出 → STAGE_HINT + 唯一出口清洗）；
- project-nn 独立包整理 + nn_pet class 重构 + 目录分类 + 本文档体系。
