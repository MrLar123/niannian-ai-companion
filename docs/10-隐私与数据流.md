# 10 — 隐私与数据流

> 数据去哪了、谁看得到、怎么删。

## 硬保证

1. **所有数据只落在 `project-nn/` 内**：
   - `xiaoyun/data/memory.db`（记忆）、`events.jsonl`（事件流）、偏好 txt；
   - `logs/*.log`（运行日志）、`前端事件日志.txt`；
   - 不写系统图片/文档/AppData（除用户级环境变量中的 Key）。
2. **截图只活在内存**：感知截图算完 dhash 与 JPEG 即弃，不落盘、不重放、无"关键帧存档"。
3. **or_proxy 仅监听 127.0.0.1**：局域网内其他设备不可达。
4. **无遥测、无自动更新**：不存在任何"回报 home"的调用。

## 出网清单（完整枚举）

| 数据 | 去向 | 触发时机 | 可关 |
|---|---|---|---|
| 对话文本 | 方舟/魔搭/OpenRouter（你配的 Key） | 每轮对话 | 否（核心功能） |
| 语音音频 | 豆包流式 ASR / 百度 REST（若配） | 说话时 | 可切本地 whisper（`XIAOYUN_ASR_PROVIDER=whisper`） |
| 合成文本 | 豆包 TTS | 她说话时 | 可切 edge（也要网）/ GSV（全本地） |
| 感知截图+窗标题 | 豆包 Vision（AgentPlan） | 仅画面变化时 | 可 `XIAOYUN_PERCEPTION=0` |
| embed 文本 | Ollama（本机 127.0.0.1） | 记忆写入/检索 | 本机，不出网 |

**未出网**：记忆内容、事件明细、聊天历史、戳一下/眼神坐标、模型文件。

## 敏感数据防护

- API Key 全部走用户级环境变量，源码不硬编码；or_proxy 启动会告警"Key 出现在对话里请轮换"；
- 记忆抽取提示词不含隐私红线（**待补 P2**：不复述密码/密钥/金额——对齐 whalepal）；
- 出站域名白名单（**待补 P2**）：当前靠"只配了三家的 Key"事实上限流。

## 删除

| 数据 | 方法 |
|---|---|
| 长期记忆 | `POST /api/memory/clear` 或删 `data/memory.db`（后端重启重建） |
| 事件流 | 删 `data/events.jsonl` |
| 对话历史 | `POST /api/reset`（软重置，不删长期记忆） |
| 全部 | 删除整个 project-nn 目录即净身（Key 在系统环境变量需另行清理） |
