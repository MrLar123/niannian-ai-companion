## 无头页面测试铁律（踩坑沉淀）

1. Chrome `--headless` 带 `--disable-gpu`（SwiftShader 崩溃 → 页面重载丢 fetch 垫片）；**但 WebView2 桌宠真机/远程调试验证不要带**（会拿不到真实渲染结果，见 `PMX表情体检报告.md`）——两个场景别混用；
2. 截图与断言分离（captureScreenshot 崩溃会连带丢页面状态）；
3. CDP 采样抖动 200ms，**禁精确 dt 断言**；
4. 有 VMD 在播别断言眼骨绝对值；
5. `--virtual-time-budget` 对 42MB WebGL 模型总是过早截图——验证改用结构解析+CDP 真机式；
6. headless 最小视口宽 504px——窄面板截图会被裁。

## 抓屏/坐标测试纪律

1. 必须 `SetProcessDpiAwareness(2)`（125% 缩放下逻辑坐标偏 1.25 倍，曾经把"完全居中"误判成"偏右 82px"）；
2. 验证透明用 PrintWindow+PW_RENDERFULLCONTENT（BitBlt 抓不到分层窗口，永远"色差=0"假通过）；
3. 判 GUI 死活看窗口（FindWindow+IsWindowVisible），不信进程/pid 文件；
4. `WindowFromPoint` 命中 ≠ 真实点击可达（Ghost 窗压住时它仍返回目标窗）——合成点击（SendInput）验证。
