# 01 — 项目大纲

> 念念桌宠（工程名小芸，project-nn）的定位、愿景、范围与成功标准。
> 与上游项目的关系：起点是 Luna 整合包（AI-Vtuber），感知管线设计借鉴 WhalePal，其余全部自研。

## 1. 一句话定位

**一只住在你桌面、会说话、会看你、记得住你的 3D 桌宠女友。**

她不是网页应用，不是聊天框，而是一个 Windows 原生进程组合：
透明置顶的 VRM/PMX 桌宠窗口 + 云端大脑（三上游自动路由）+ 全双工语音 + 屏幕感知 + 语义长期记忆。

## 2. 愿景

做一个"陪伴而非指挥"的桌面 AI：

1. **有形象**——3D 角色而不是头像，有眼神、有口型、有物理反馈（戳一下会瘪嘴）；
2. **有声音**——全双工语音对话，她说话带情绪（语速/音调随内容变化），你说话她随叫随到；
3. **有记忆**——记得你是谁（事实层）+ 记得你今天干了什么（事件层）；
4. **有分寸**——工作时不插嘴，深夜只催睡，沉默也是一种陪伴；
5. **可塑**——19 套人设、20+ 形象、15 套舞蹈、四档 TTS 引擎全部托盘热切换。

## 4. 范围

**In**：
- Windows 10/11 单机运行，双 bat 启停；
- 文字 + 语音对话，形象/人设/音色/动作热切换；
- 屏幕感知与主动搭话（带门控）；
- 全部数据落 `project-nn/` 内。

**Out（明确不做）**：
- 直播平台接入（AI-Vtuber 的核心场景，桌宠不需要）；
- 多语言 UI（纯中文）；
- 移动端 / Web 端；
- 多用户/账号系统。
