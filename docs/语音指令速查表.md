# 语音指令速查表（分层路由 Phase 1）

> 生效：重启小芸桌面后。所有指令走 L1 规则层（<1ms），未命中自动落回正常对话。
> 通用句式：**切音色** = "把声音换成 __ / 换成 __ / 用 __ 的声音 / 音色切成 __"；**做动作** = "跳/来/做/演 + 动作名"。
> 防抖冷却：同一音色 6 秒、同一动作 10 秒内重复说 → 她只回应不重复执行。
> 缺槽位（"跳个舞"）她会反问；歧义（台湾/女友/少女）她会报出两个候选让你点。

## 〇、总规则（先读这个）

| 规则 | 说明 |
|---|---|
| 指令长度上限 | **40 字以内**才算指令，长句一律当对话 |
| 优先级 | 停动作 > 动作 > 音色 > 模型（一句话多意图取靠前的半句） |
| 槽位是闸门 | 动词命中但槽位（名字）点不中 = 不算指令，照常聊天（"换成现金"不会误触） |
| 生僻名 → 编号 | 名字 ASR 转不准就说编号，**数字是语音识别最稳的词** |
| 歧义反问 | 一词多候选（卡夫卡/飞雪/台湾/女友）她会报出候选让你点 |
| 越界保护 | "变成三十号"不触发指令，正常聊天 |

## 三、停止 / 其它

| 说法 | 效果 |
|---|---|
| "停下来休息吧"、"别跳了"、"回到待机"、"站好" | 动作回内置待机（呼吸/歪头/挥手） |
| "跳个舞"、"来个动作②" | 她反问："想看哪个呀？我这有：……" |
| "换个声音嘛" | 她反问可换的音色 |
| "你会跳舞吗"、"你最喜欢什么舞蹈" | 不触发指令，正常聊天回答 |

> ②注："做个动作"四个字连说会直接播 lxjwwc（它的展示名就叫"动作"）；"跳个舞/来个动作"（带量词但不点名）才走反问。

## 五、语音指令的边界（防误触设计）

| 设计 | 说明 |
|---|---|
| 40 字上限 | 指令都是短句，长句整句落回对话大脑 |
| 动词+槽位双闸 | 只有动词（换/切/变成/来个…）**且**槽位（名字/编号）都命中才算指令 |
| 同分反问 | 别名值是列表时（卡夫卡/飞雪）绝不瞎猜，她报候选让你点 |
| 单字名带动词 | "摇"单字无动词不触发（"摇了吧"是聊天）；"来摇一个"才播 |
| 中文数字 | "十二号"支持一~十九；纯数字"12号"同样支持 |
| 越界回落 | 编号超范围（三十号）→ 正常聊天，不报错 |
