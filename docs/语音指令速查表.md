## 五、边界（为什么有些话她不动）

| 设计 | 说明 |
|---|---|
| 40 字上限 | 超过就整句落回对话大脑 |
| 整数名命中优先 | 名字本身就叫这个 = 你说的是它；带后缀的（"雷电将军 · 素体"）必须说全 |
| 间隔号不发音 | "卡芙卡 · 泳装"说成"卡芙卡泳装"照样命中（归一化时去掉间隔号与标点） |
| 单字名必须带动词 | "摇"单说不动；"来摇一个"才播 |
| 疑问句不动手 | "你会跳舞吗""你什么性格"都是聊天 |
| 同前缀歧义必反问 | 绯雪一形态/二形态 这种不猜 |
