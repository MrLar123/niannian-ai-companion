> 日常开发改代码的生效方式、诊断手段、常见故障速查。

## 1. 改代码的生效方式（重要）

| 改了什么 | 生效方式 |
|---|---|
| `xiaoyun_server.py`（后端） | 必须 Stop → Start（进程启动读一次） |
| `desktop_app.py`（壳） | 只换壳：`Restart-Pet.ps1` 会检测代码新旧只换壳 |
| `or_proxy.py` | `Swap-Brain.ps1` 热换血（其余组件不动） |

| `*.html` 页面 | WebView2 有缓存：后端已加 `Cache-Control: no-store`；顽固时清 `%LOCALAPPDATA%` 对应 profile |
| 人设 JSON | 热生效（POST /api/preset 或托盘） |

## 3. 故障速查表

| 症状 | 优先查 | 命中特征 |
|---|---|---|
| 双击 bat 无反应 | bat 编码/行尾 | 必须 ASCII+CRLF；报"不是内部或外部命令"=编码问题 |
| 桌宠看不到 | 窗口位置/僵尸 | `窗口是否在可视区外`；有进程没窗口=僵尸，先 Stop |
| 点击没反应 | Ghost 窗 | WindowFromPoint 返回 `Ghost`/标题带"(未响应)" → 杀僵尸 |
| 点击偶发失效 | 坐标漂移 | 日志"按下命中=身体区"但用户点的 mic → rect 过期，看 age |
| 她不回话 | 两条日志分界 | 有"转写完成"无"收到识别文字"=消费者侧；连转写都没有=采集/阈值 |
| 卡"准备开口" | playing 上报 | `playback_dur=0` = 页面没上报（流式路径漏 reportPlaying） |
| 对话 502 | or_proxy 额度 | health 的 quota_cooldown / errors；全链烧光才 502 |
| 模型自言自语 | 回授 | 检查输入设备是不是音箱采集端点 |
| 刘海翘起/头发飞 | VRM 铁律 | update 传了绝对秒数 / 模型被缩放 |
| 启动日志停在 ASR | 8091 | 503 = ASR 没起来；查 asr_err.log |

## 4. 发布/同步纪律

- `D:\LunaAI\xiaoyun`（开发树）与 `D:\LunaAI\project-nn\xiaoyun`（发布树）**双树同步**：改完一侧必须 sync（脚本/日志路径已双树一致）；
- 大文件（模型权重）用 cp 后 du 对账；
- 沙箱内 agent 拉起的常驻进程活不过回合——**启动验证用临时端口前台跑完即杀**，正式启动由用户双击 bat。

## 5. 脚本编码三铁律

1. `.bat` 纯 ASCII（0 非 ASCII 字节），中文进 `.ps1`；
2. `.ps1` 必须 UTF-8 **BOM**（PowerShell 5.1 否则中文乱码）；写文件用 `open(f, encoding=原编码)` 探测后回写，保 BOM；
3. 行尾 CRLF；`timeout /t N` 在 Git Bash 会被 MSYS 转换搞坏，用 `ping -n N 127.0.0.1`。

## 6. PowerShell 坑清单

| 坑 | 正解 |
|---|---|
| `if(Func())` 语法报错 | `$ok = Func; if($ok)` |
| `$pid` 是只读自动变量 | 循环变量换名 |
| `@($null).Count == 1` | 函数返回空集合时过滤 $null |
| 按命令行杀进程会杀到 shell 自身 | 白名单排除 powershell/cmd/conhost |
| 会话环境 HTTP_PROXY/http_proxy 重复键 | `[Environment]::SetEnvironmentVariable($k,$null,'Process')` 先清再设 |
| `FindWindow` 传 $null 转空串 | 签名用 IntPtr 传 `[IntPtr]::Zero` |
| 互斥量同线程重入 | 并发测试必须跨进程占锁 |
