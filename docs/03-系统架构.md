## 2. 端口契约

| 端口 | 进程 | 协议 | 说明 |
|---|---|---|---|
| 8090 | xiaoyun_server | HTTP | 后端总入口（API + 页面 + assets 静态） |
| 8091 | asr_service | HTTP | 只做"听和转写"，`allow_reuse_address=False` 端口独占 |
| 8787 | or_proxy | HTTP | OpenAI 兼容对话代理（仅监听 127.0.0.1） |
| 11434 | Ollama | HTTP | 仅 bge-m3 embed（不可用自动降级关键词，不影响对话） |
| 9880 | GPT-SoVITS（可选） | HTTP | 本地克隆声线，按需拉起，空闲 900s 自动释放 |

## 3. 关键数据流

### 3.1 一轮文字对话
```
页面/壳 → POST /api/chat {text}
  → ReplyPipeline: 人设+STAGE_HINT 注入 messages → or_proxy /v1/chat/completions
  → _strip_stage_text() 清洗（唯一出口）
  → HISTORY 入库 + SEQ 自增
  → tts 合成（情绪偏移）→ base64 返回
页面 → GET /api/last?since=N → seq 变化 → LAST_CLAIM 播放权认领 → 播放
页面 → POST /api/voice/playing {seq, dur} → 后端等 start+dur+0.8 → 恢复收音
```

### 3.2 一轮语音对话
```
麦克风 → ASR VAD 判说完 → 转写 → pending
后端消费者 → POST 后端 /api/voice/consume → _brain_turn() → _publish_reply()
  → 页面播放（流式 WebAudio / 整段 audio）→ reportPlaying → 收尾闸 → 开麦
```

### 3.3 屏幕感知
```
感知线程 60s → mss 截屏 → dhash64 → 窗口去重(汉明≤4)
  → 变化 → JPEG(≤960) + 前景窗标题 → 豆包 Vision → 结构化 JSON
  → events_store 入库 → signal(error/success) → _speak_proactively → 开口权由 speak 字段
```

## 4. 线程模型（桌面壳）

| 线程 | 职责 | 关键约束 |
|---|---|---|
| 主线程 | pywebview 消息循环 | JS 桥同步回环在此执行——**禁止高频调用** |
| Catcher | 隐形点击层消息泵 | WndProc 回调只做 O(1)（教训：EnumWindows 导致整机卡死） |
| CursorPoller | 20Hz 光标采集 | 句柄缓存 + IsWindow 校验，MIN_STEP=3px 去抖 |
| RectPoller | 0.5s 控件坐标 | 走 HTTP 不走 JS 桥 |
| HotkeyThread | 全局热键 | 同线程补注册（跨线程收不到 WM_HOTKEY） |
| watchdog | 捕获层存活探测 | SendMessageTimeout 探无响应，连续 2 次撤层 |

**跨线程 WinForms 操作铁律**：`run_guarded(fn, timeout)` 包裹，超时放弃；
失败降级纯 Win32（ctypes 调用会释放 GIL）。

## 5. 存储布局

| 路径 | 内容 |
|---|---|
| `xiaoyun/data/memory.db` | 长期记忆（FTS5 + vectors 表），WAL 模式 |
| `xiaoyun/data/events.jsonl` | 感知事件流（单段封顶 600s，保留 7 天） |
| `xiaoyun/data/gaze_mode.txt` / `poke_style.txt` | 用户偏好 |
| `xiaoyun/assets/models/current.txt` | 当前形象 key（**运行时只走 API 写**） |
| `xiaoyun/人设/current.txt` / `voice_override.json` | 当前人设 / 音色覆盖 |
| `runtime/app/config.json` | 模型选择（openai.model / chatgpt.model 双写） |
| `logs/*.log` | 各组件 out/err 分文件 |
| `前端事件日志.txt` | 页/壳/后端/ASR 四层共写（排查命脉） |
