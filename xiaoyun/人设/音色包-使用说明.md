**改完后端必须重启才生效：双击桌面「重启小芸桌面.bat」。**

## 一、做了哪四件事

| # | 改动 | 你要感知到的变化 |
|---|---|---|
| 1 | **音色跟随人设**（修 bug） | 换人设时声线真的会变。此前 19 套人设各自配的声线一直被覆盖，换人设听感不变 |
| 2 | **语感签名 catchphrase**（19 套） | 同一句话，不同人设说出来的句式、语气词不一样。内容仍是现生成的，不会变复读机 |

## 二、怎么用

### 第 0 步：重启
双击 **「重启小芸桌面.bat」**（在 DeskBox 的 `桌面小芸` 目录里）。
不重启的话，跑的还是旧进程，什么都听不出来。

### 第 1 步：切人设（并听她自报）
三种入口任选：

- **托盘菜单**：小芸托盘图标 → 人设子菜单 → 点一套
- **设置页**：浏览器打开 `http://localhost:8090/settings` → 陪伴 → 选人设
- **命令行**：`POST /api/preset  {"key":"dushe"}`

切完她会**立刻说一句**，例如：
- 毒舌 → 「别指望我换个人格就变温柔，不可能。」
- 慵懒 → 「唔……换个样子好累。你满意就行。」
- 三无 → 「……知道了。」

**这句话就是试听**：声线、语速、语感、人格四件事一起换，一句话全听得出来。

### 第 2 步：想自己挑音色（可选）
托盘 → **音色** 子菜单 → 选一个（豆包 2.0 共 5 个：通用VV / 高冷御姐 / 柔美女友 / 美女女友 / 小何）。

**只要手动选过一次，就进入「锁定音色」状态**：之后换人设只换人格和语速，声线保持你选的那个。这是有意的——你自己挑的优先。

### 第 3 步：想恢复「跟随人设」
编辑 `xiaoyun/人设/voice_override.json`，把
```json
"follow_preset": false
```
改回 `true`，然后重启后端。

### 第 4 步：验证有没有生效（可选）
```

```
12 项全 PASS 就是接上了。

## 三、判断生效的简易标准

切到「毒舌」这一套，应当同时满足三条：
1. 声音变成 **高冷御姐** 声线（不是原来的通用女声）
2. 她说的话是「别指望我换个人格就变温柔，不可能」这一类
3. 托盘音色菜单里当前项也跟着变成了「豆包 · 高冷御姐」

三条都对 = 全链路通了。

## 四、想自己改内容

所有内容都在 `xiaoyun/人设/<人设名>.json` 里，改完**不用重启**，切一次人设就重新加载：

- `catchphrase` —— 语感签名。写"句式节奏 + 语气词 + 开头收尾习惯"，**别写台词**。
  例：`"先撩后崩：前半句从容，后半句慌；爱用「怎么，盯着我？」起头"`
- `lines.switch` —— 切换时的自报句。数组，随便加几句，她每次随机挑一句。
- `volc_speaker` —— 这套人设默认用的声线（跟随模式下生效）。
- `volc_rate` —— 语速偏移，-50~100。慵懒是负的，元气是正的。

两个批量脚本可重跑（只覆盖这两个字段，不动别的）：
```
python tools/add_catchphrase.py     # 重写 19 套的 catchphrase
python tools/add_lines.py           # 重写 19 套的 lines.switch
```

## 五、几个已知行为（不是 bug）

1. **切人设有时她不说话**：她正在说话（busy/speaking），或者宠物窗不在线时，会主动跳过自报。设计如此，避免打断和往聊天窗硬塞。
2. **切人设不会清记忆**：人设只改"她怎么说话"，长期记忆、上下文都不动。
3. **真人声线克隆不做**：只用官方授权音色，这是红线。
4. `/settings` 页面也是本次才加的，同样需要这次重启后才不 404。
