# 🌙 念念 · 桌面 AI 伴侣

**一只住在你桌面上的 3D 小镇姑娘——会听、会说、会看、会记、有情绪。**

## 她会做什么

🎭 **31 套 3D 形象，随口就换**
甘雨、雷电将军、卡芙卡泳装……全部按「角色 · 服装」分好组。
不用点菜单——直接说「换成甘雨」，听岔了她会反问「你说的是甘雨吗？」，答「对」就换好。

🎙️ **真正的全双工语音对话**
点一次麦克风，之后全程免按键：你说话 → 她听 → 她回答 → 豆包流式 TTS 边收边播
→ 口型跟着声音逐帧对齐 → 说完自动继续听你讲。语音首响 0.38~0.45 秒，像打电话，不像对讲机。

😊 **有情绪，有表情**
她开口时先过一层本地情绪判定，再用大模型复核；喜怒哀惊直接驱动 3D 脸上的 7 组表情——
**31 套形象 × 8 种情绪 = 248 格表情逐格像素级标定，全部达标**。念台词不会面瘫。

👀 **她一直看着你**
眼神平滑追随你的光标（20Hz），被戳会瘪嘴抗议，连戳会嫌弃。
这些「活着」的小信号是产品的核心，不是彩蛋。

🧠 **记得住你们的一切**
长期记忆 = SQLite 全文检索 + 向量语义召回双路融合。上周聊过的游戏、你的习惯、
你随口提过的生日，她都拎得出来。空闲时她还会主动搭话——深夜的主动搭话只有一个意图：催你睡。

🖥️ **知道你在忙什么**
每分钟看一眼屏幕（截图只在内存、算完即弃），识别出你在写代码 / 开会 / 打游戏。
屏幕报错时她会心疼地安慰一句；日常操作她保持安静——**沉默也是一种陪伴**。

🗣️ **19 套人格 × 21 种音色**
傲娇、毒舌、高冷御姐、小恶魔……人设管性格，音色管嗓音，两者独立切换互不干扰。

💃 **说跳就跳**
19 套 MMD 舞蹈，语音说「跳个舞」播一遍自动回待机，不覆盖你菜单里的常驻选择。

## 快速开始

```powershell
# 依赖全部打包在内（runtime/Miniconda3 + 两个独立 venv），clone 即用，无需安装
xiaoyun\scripts\启动小芸桌面.bat    # 双击：代理 → 后端 → 语音识别 → 桌面窗 全链拉起
xiaoyun\scripts\诊断小芸桌面.bat    # 出问题时一键体检（7 项）
```

只需配好 API Key（用户级环境变量，仓库内零明文凭证）：

| 环境变量 | 用途 |
|---|---|
| `ARK_API_KEY`（火山方舟） | 对话 / 视觉 / 表情判定（有免费额度） |
| `ARK_PLAN_API_KEY` | 豆包语音 TTS/ASR、生图 |
| `OPENROUTER_API_KEY`（可选） | 免费模型池兜底 |

> 三套凭证互不通用，配置细节见 [or_proxy/README_OR_PROXY.md](or_proxy/README_OR_PROXY.md)。

## 一句话架构

```
桌面壳(透明窗+托盘) ─┐
语音识别 ASR ────────┼→ 后端 Flask(8090) → or_proxy 多上游大脑 → 方舟/OpenRouter
屏幕感知(内存截图) ──┘        │                └→ 豆包 TTS 流式 / ASR / 视觉
                          长期记忆(SQLite FTS5 + 向量) + Ollama 向量模型
```

多上游大脑 `or_proxy`（单文件、零第三方依赖、零明文 Key）自动在方舟 / OpenRouter 间
择优路由：按实测延迟选模型、额度烧光自动熔断跳档、401 自动切换上游——
对话模型菜单永远只显示当前真实可用的模型。

## 为什么值得看代码

这是一个**单人在 Windows 上从零打磨的完整桌面 AI 伴侣工程**，几处少见的设计：

- **五层自听防护的语音时序机**：桌宠「听自己说话」是所有语音产品的头号坑，
  本项目用播放时长上报 / 开麦委派 / 播放期真关麦 / 守卫清零 / 回声过滤五层把它根治，
  完整时序契约见 [docs/11-语音链路与时序设计.md](docs/11-语音链路与时序设计.md)。
- **248 格表情逐格标定**：不是「链路通了」，是每套模型每个情绪都做了像素级验收
  （口径与铁律见 [docs/PMX表情体检报告.md](docs/PMX表情体检报告.md)）。
- **语音指令的「宁问不猜」原则**：近似匹配只用来报候选反问，绝不直接改状态；
  两字名执行层禁近似（「换成甘雨」永远不会被误听成某个音色）。
- **源码零明文凭证 + 全量文档治理**：31 篇编号文档 + 5 份实测调研报告，
  全部与代码同步校准（一键校验脚本在 `xiaoyun/tools/`）。

## 隐私

- 所有数据只落在项目目录内，无遥测、无自动更新；
- 截屏只在内存里活几毫秒，只有画面变化时才发给你自己配置的视觉端点；
- 语音可全本地（whisper 不出网），云端通道按需开启；
- `or_proxy` 只监听 127.0.0.1，仓库零明文凭证。
